# Glass — published privacy notice

This branch exists only to serve the privacy notice for **Glass: DECA Study App**
via GitHub Pages. It has no history in common with the code branches and
deliberately contains nothing else, so the published page is the notice and
nothing but the notice.

- `index.html` — the notice itself. This is the canonical copy.
- `privacy.html` — redirects to `index.html`, so an older link still resolves.
- `.nojekyll` — serves the files as-is rather than running them through Jekyll.

Published at <https://iam-invisible.github.io/Glass-DECA-App/>

The same text is embedded in the app under **Settings ▸ About ▸ Privacy notice**,
and is kept in step with `LCVI DECA Study App/Data/PrivacyPolicy.swift`. If one
changes, change the other.
